# `.github`

Organization-wide defaults for RentRewards.

## What this repository is

A repository named `.github` is treated specially by GitHub. Certain files placed
here are read at the organization level and applied across RentRewards, rather
than belonging to this repository alone. Editing a file here can therefore change
what appears on the organization page or in other repositories.

## What's in here

| Path | Purpose |
| --- | --- |
| `profile/README.md` | The public organization profile shown at github.com/RentRewards |
| `README.md` | This file — documentation for anyone working in this repository |
| `SECURITY.md` | How to report a vulnerability; the default for repositories without their own |

## Making changes

This repository is public, and so is everything committed to it. Nothing
internal, confidential or unreleased belongs here.

Changes to `profile/README.md` become publicly visible as soon as they land on
the default branch. Review that file with the same care you would give anything
published under the organization's name.
